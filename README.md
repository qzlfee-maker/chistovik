# ЧИСТОВИК - Сайт-портфолио частного мастера

Витрина услуг по обработке и реставрации фотографий, дизайну открыток, созданию песен на заказ и монтажу памятных видео.
Стек: **Vite 5 + React 18 + TypeScript 5 + CSS Modules**.

---

## 1. Запуск в режиме разработки

Установите зависимости и запустите локальный сервер:

```bash
npm install
npm run dev
```

После запуска откройте адрес, указанный в терминале (обычно `http://localhost:5173`).

---

## 2. Сборка для продакшна

Для проверки типов и сборки статических файлов выполните:

```bash
npm run build
```

Чтобы локально проверить собранную версию:

```bash
npm run preview
```

Готовая статика появится в папке `dist/`.

---

## 3. Как заменить Telegram-юзернейм

1. Откройте файл `src/config/site.ts`.
2. Найдите поле `telegramUsername: 'chistovik_master'`.
3. Замените `'chistovik_master'` на ваш реальный ник в Telegram (без символа `@`).
4. Все кнопки и ссылки на сайте обновятся автоматически.

---

## 4. Как заменить работы (портфолио)

1. Положите ваши изображения (рекомендуется формат `.webp` или `.avif`) в папку `public/works/` или `src/assets/`.
2. Для главного изображения в первом экране откройте `src/components/ui/Placeholder/HeroPlaceholder.tsx` и замените `<Placeholder ... />` на тег `<img src="/путь-к-файлу.webp" alt="Описание работы" />`.
3. Для галереи работ откройте `src/components/sections/Works/Works.tsx` и `src/components/sections/Works/WorkItem.tsx` - замените компонент `<WorkPlaceholder ... />` на `<img src="..." alt={item.title} loading="lazy" />`.

---

## 5. Как заменить отзывы

1. Откройте файл `src/data/reviews.ts`.
2. Замените имена клиентов, услуги и тексты в массиве `reviews` на настоящие отзывы ваших заказчиков.

---

## 6. Как заменить цены

1. Откройте файл `src/data/prices.ts`.
2. Отредактируйте названия позиций, стоимость (`price`) и примечания (`note`).

---

## 7. Как поменять цвета и шрифты

1. Откройте файл `src/styles/tokens.css`.
2. Измените значения CSS-переменных в блоке `:root` (например, `--bg-main`, `--bg-card`, `--accent`). Изменения применятся ко всему сайту.

---

## 8. Деплой

Проект собирается в чистую статику без серверной части.
Чтобы опубликовать сайт:
1. Выполните команду `npm run build`.
2. Загрузите содержимое папки `dist/` на любой хостинг статики: **Vercel**, **Netlify**, **GitHub Pages**, **Cloudflare Pages** или обычный веб-хостинг.
